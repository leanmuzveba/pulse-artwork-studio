Step 2 — Parallel AI Generation (4 outputs from 1 topic)

The augmented prompt is sent in parallel to four specialised generation modes. Each returns a different output type.
Script Generation
Input: Topic + RAG context + format instructions
API: Claude Sonnet 4.6 (primary) → Gemini Flash (fallback)
Output: 30-45s script with HOOK / VALUE / CTA structure
Time: 5–12 seconds
Hashtag Generation
Input: Topic + DTF niche context
API: Groq Llama 3.1 (fast, free) → Claude fallback
Output: 25 tags in 4 groups: HIGH VOLUME / DTF NICHE / BUSINESS / LOCAL
Time: 3–8 seconds
Hook Concept Generation
Input: Topic + social media hook frameworks
API: Claude Sonnet 4.6
Output: 5 × hook concepts each with VISUAL / AUDIO / PATTERN INTERRUPT
Time: 8–14 seconds
Avatar Script Generation
Input: Topic + talking-head format + stage direction instructions
API: Claude Sonnet 4.6
Output: 60-90s script with [PAUSE], [SMILE], [GESTURE] markers
Time: 10–15 seconds

Key architectural decisions: Client-side video rendering (FFmpeg.wasm) eliminates server egress costs. API keys stored only in the browser (never server) to avoid liability. pgvector in Supabase avoids a separate vector DB (Pinecone) during MVP. Vercel hobby tier + Railway $5 plan keeps monthly hosting cost under R 100.
