BRANCH STRATEGY
---------------
main        = production-ready releases
develop     = integration branch
feature/*   = individual features
fix/*       = bug fixes
release/*   = release preparation
hotfix/*    = urgent production fixes

KEY RULES
---------
1. Never commit secrets or API keys.
2. Every feature gets tests.
3. API contracts are versioned.
4. Database migrations are committed.
5. Pull requests require review before merge.
6. AI/image jobs must be asynchronous.
7. Original artwork is immutable.
8. Large files live in object storage, not Git.
